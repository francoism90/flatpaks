@SITE_TITLE@

Unofficial Flatpak builds of apps and SDK extensions that Flathub does not carry. Sources and build pipeline: @HOMEPAGE@.

Add the remote

Runtimes come from Flathub, and flatpak only resolves them from remotes in the same installation scope, so add both to the same scope (--user or system-wide). 

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists flatpaks @SITE_URL@/index.flatpakrepo

Install

flatpak install flatpaks com.visualstudio.code
flatpak install flatpaks ai.claude.desktop
flatpak install flatpaks org.freedesktop.Sdk.Extension.podman

Signed with a GPG key; the public key is embedded in index.flatpakrepo.
